# سهرة الشلة

ألعاب سهرة للشلة على الموبايل: **حرب الحروف**، **سين جيم**، **ممنوع تقول**، و**برا السالفة**.
كل لعبة فيها سهل ووسط وصعب.

- الموقع ملف `index.html` واحد مع مجلد `assets` (خطوط ومكتبات)، ما بيحتاج أي سيرفر خاص.
- اللعب من كذا موبايل والانضمام بكود QR شغالين عن طريق سيرفرات MQTT مجانية عامة
  (`broker.hivemq.com` و `broker.emqx.io`). بيتصل بالاتنين سوا، فإذا واحد وقف بيكمّل عالتاني.
- لتجرّب على سيرفر MQTT تاني: زيد `?broker=wss://your-broker:8084/mqtt` لرابط الموقع.
